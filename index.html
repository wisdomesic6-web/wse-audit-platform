Setup Guide
1️⃣
Create an Airtable base
Go to airtable.com → New base → name it "WSE Audit Clients"
2️⃣
Create a "Clients" table
Add fields: Company (text), Code (text), Period (text), Step (number), Status (text), Txns (number), Flags (number), Notes (long text)
3️⃣
Get your token & Base ID
Token: airtable.com/create/tokens (scopes: data.records:read, data.records:write)
Base ID: from the URL — airtable.com/appXXXXXX/...
4️⃣
Enter credentials above & connect
